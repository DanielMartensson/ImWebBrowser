ImWebBrowser

A kiosk-grade web browser on SDL3 + Dear ImGui + WPE WebKit, rendering pages through a zero-copy DMA-buf pipeline with your choice of OpenGL ES 3 or Vulkan rendering. This is the living manual — hover anything.

WebRTC backend

ENABLE_WEBRTC=ON only exposes the RTCPeerConnection API to pages. Which engine implements it is chosen when WPE WebKit itself is built, via its CMake flag USE_GSTREAMER_WEBRTC: ON (WPE default) → GstWebRTC over GStreamer’s webrtcbin; OFF → WPE’s bundled libwebrtc stack.

GstWebRTC needs the GStreamer webrtc/rtp/sdp components (≥ 1.20) and OpenSSL ≥ 3.0 in the runtime image, plus libnice for ICE transport (not to be confused with the unrelated librice build option). ImWebBrowser runs GstWebRTC on both the Linux dev PC and the STM32MP257F target (built for Vulkan + GStreamer hardware decode). Verify the live engine with gst-inspect-1.0 webrtcbin.
