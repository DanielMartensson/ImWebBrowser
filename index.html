Overview

ImWebBrowser embeds WPE WebKit into a raw SDL3 window using EGLStream-free DMA-buf export: WebKit's compositor hands us each frame as an EGLImage, which becomes GL texture storage directly on the GPU.

The GUI thread does exactly three things per frame: pump events, import the newest frame, present it. Everything else — layout, JS, rasterization — lives in WebKit's own processes (WebProcess / compositor).

Build & run

sudo apt install libsdl3-dev libwebkit2gtk-4.1-dev libwpe-1.0-dev \
     libwpebackend-fdo-1.0-dev libxkbcommon-dev libglib2.0-dev \
     libegl-dev libgles2-mesa-dev

cmake -B build -DCMAKE_BUILD_TYPE=Release -DENABLE_BENCHMARK_HARNESS=ON
cmake --build build -j$(nproc)

./build/imwebbrowser https://example.org          # windowed
./build/imwebbrowser --kiosk                      # fullscreen direct-blit
./build/imwebbrowser --bench-fish 5000            # automated aquarium

Vendored Dear ImGui lives in src/libraries/imgui. Everything else comes from the distro.
